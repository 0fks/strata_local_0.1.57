# 검증 범위

Strata 엔진 0.1.57과 SC117의 IQ3_S, IQ3_XXS, IQ2_XS를 지원합니다. 원본 vendor 코드와 라이선스 및 현재 실행 중인 Strata는 변경하지 않았습니다. 기본 포트는 18765입니다.

SC117 고정 revision의 GGUF 6개 크기·SHA-256을 원본 저장소 메타데이터에서 확인했습니다. 작은 실제 GET으로 GGUF 헤더·크기, 공통 MTP 4파일의 Range 응답, 이미지 인코더, GitHub 엔진 주소를 확인했습니다. MTP dense.txt는 전체 내용의 고정 해시도 대조했습니다.

자동 테스트는 모델별 실행 설정·OpenCode 모델 ID, 공통 파일 중복 방지, 생성 pack의 손상·다른 모델 감지, 3종 준비 및 재실행 흐름을 검사합니다. 통합 테스트는 작은 대체 파일을 사용하며 실제 수백 GB 모델 다운로드나 변환·추론을 대신하지 않습니다.

IQ3_S는 원본 모델·가중치의 고정 크기와 해시를 유지합니다. pack 텍스트/JSON은 줄바꿈·JSON 표현 차이를 정규화한 고정 해시를 사용하며 compat-bf16.json의 source 절대경로는 파일명으로 비교합니다. 추가 모델의 pack은 고정 GGUF에서 변환하고 생성 해시를 별도 기록합니다. 새 모델 전체 변환·추론·속도 비교는 새 PC에서 검증해야 합니다.

2026-11-08: 실제 SC117 IQ3_S 모델을 다른 소스 경로로 연결해 원본 도구로 pack을 다시 생성했습니다. 기존 원시 해시는 compat-bf16.json만 실패했고, 수정한 검사에서는 모든 pack 파일과 기존 dense.bin 해시가 통과했습니다. 현재 실행 중인 서비스와 모델은 변경하지 않았습니다.
