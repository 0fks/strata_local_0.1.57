# 검증 범위

원래 사용하던 SC117 IQ3_S 2분할 프로필과 Strata 엔진 0.1.57로 복원했습니다. 모델·pack·MTP·이미지·엔진의 24개 파일 크기·SHA-256 및 실행 설정은 기존 SC117 배포본 기준입니다.

기본 API 포트 18765, 다운로드 폴더 지정·이동 후 경로 변경, 연결 진단 기능은 유지합니다. Unsloth용 생성 pack 해시 방식 대신 검증된 SC117 pack 고정 해시를 사용합니다.

원본 vendor 소스와 라이선스는 변경하지 않았습니다. 현재 실행 중인 Strata는 변경하거나 재시작하지 않았습니다. 이번 복원에서는 새 PC의 전체 다운로드·설치·추론을 다시 수행하지 않습니다.
